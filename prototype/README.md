# Cheery Outlet Platform — HTML Prototype

`Cheery Outlet Platform.html` is the original single-file, client-side prototype (no backend, in-memory state, simulated clock). Open it directly in a browser.

**Status: context only, not a specification.** It shows what might be part of the product (guest booking, host, waiter, kitchen, manager and admin views). Many behaviours are simulated (payments, messages, offline, permissions, reports). It was built around one customer's needs (AU, AUD, GST, Square, "JA² Club").

How it is used:
- Feature inventory and classification: `docs/architecture/stage-a-prototype-analysis.md` and `docs/architecture/01-product-and-requirements.md` §2.
- Decisions that supersede the prototype: `docs/architecture/decision-log.md` (e.g. D-02: prototype is context, not spec).

Keep changes to the prototype in this folder and note what changed in the commit message so reviews can compare versions.
